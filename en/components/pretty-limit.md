## Overview

The `PrettyLimit` component is a UI element designed to display text with a character limit in a visually appealing way. It is particularly useful for displaying truncated text with an option to expand on hover, without affecting the layout.

<a name="usage"></a>
## Usage

To use the `PrettyLimit` component, you can define it in your Blade views or use it programmatically in your PHP code.

<a name="customization"></a>
## Customization

The `PrettyLimit` component can be customized using several options:

- **Color**: Set the color theme using predefined options like `primary`, `secondary`, etc.
- **Label**: Add a label to the component for context.
- **Limit**: Define the maximum number of characters to display before truncation.

<a name="themes"></a>
## Themes

The component supports various themes that can be applied using the `color` attribute. Available themes include:

- Primary
- Secondary
- Success
- Warning
- Error
- Info
- Custom colors can also be applied using CSS variables.
