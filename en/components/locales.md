# Locales

The `Locales` component adds a button to layout to change the current locale.

~~~tabs
tab: Class
```php

```
tab: Blade
```blade
<x-moonshine::layout.locales/>
```
~~~

For more information about localization, see the [Localization](/docs/{{version}}/advanced/localization) section.
