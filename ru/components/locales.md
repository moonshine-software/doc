# Locales

@include('_includes/note-about-appearance-layout')

Компонент `Locales` добавляет в шаблон кнопку для смены текущей локали.

~~~tabs
tab: Class
```php
Locales::make()
```
tab: Blade
```blade
<x-moonshine::layout.locales/>
```
~~~

Подробнее о локализации читайте в разделе [Локализация](/docs/{{version}}/advanced/localization).
