<a name="overview"></a>
## Обзор

Компонент `PrettyLimit` предназначен для отображения текста с ограничением по количеству символов в визуально привлекательной форме. Он особенно полезен для отображения усеченного текста с возможностью расширения при наведении, без изменения макета.

<a name="customization"></a>
## Настройка

Компонент `PrettyLimit` можно настроить с помощью нескольких параметров:

- **Цвет**: Установите цветовую тему, используя предустановленные варианты, такие как `primary`, `secondary` и т.д.
- **Метка**: Добавьте метку к компоненту для контекста.
- **Лимит**: Определите максимальное количество символов для отображения перед усечением.

<a name="themes"></a>
## Темы

Компонент поддерживает различные темы, которые можно применить с помощью атрибута `color`. Доступные темы включают:

- Основной
- Вторичный
- Успех
- Предупреждение
- Ошибка
- Информация
- Также можно применять пользовательские цвета с помощью CSS-переменных.
